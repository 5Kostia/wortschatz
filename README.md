# Wortschatz (приложение)
Офлайн-приложение для немецких слов (PWA): те же 6 разделов, что в боте. Данные и прогресс хранятся на телефоне (IndexedDB).
Публикация: залить файлы в репозиторий GitHub, включить GitHub Pages, открыть ссылку в Safari и добавить на экран «Домой».
Файлы: index.html (интерфейс), app.js (экраны), logic.js (логика повторения и проверка ответов), words.json (все слова), sw.js (офлайн), manifest.json, icon-*.png.
