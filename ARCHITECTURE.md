# Архитектура
- logic.js: чистая логика без интерфейса (проверка ответов, план вопросов, ступени 15 мин / 8 ч / 1 / 3 / 7 / 28 дней, шаг назад при ошибке). Тест: `node` с assert.
- app.js: экраны и действия, состояние в переменных P (прогресс: ключ `раздел:слово` → ступень, срок, верно/неверно, направление) и ST (настройки). Сохранение в IndexedDB (хранилище `kv`, ключи progress и settings) после каждого ответа.
- words.json: слова, собраны скриптом из словарей бота (ключи: u слово, d немецкий, t перевод, l уровень, a артикль, p/f формы глагола, pr/c предлог и падеж, e примеры).
- sw.js: кеш всех файлов при первой загрузке, затем работа офлайн. При обновлении приложения поменять номер версии `V`.
- Копия прогресса: экспорт и импорт JSON (кнопки в «Ещё»).
